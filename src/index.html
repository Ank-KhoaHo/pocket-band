Pocket Band

Audio needs a click first: click anything, or press a key.

Style and mood

Keys: 1-4 style · ← → mood · Space play/stop · N next · M play mode · Esc stop

Every mood is the same 16-bar tune in a new key, tempo and band. A loop takes a few seconds to build the first time; the rest build in the background.

Pick a style (1-4) and press Play.

Journeys

A set of moods played back to back in the style you picked above. Each change lands on a bar line, so the music never stops cold.

Live layers: the current mood, split into parts

Every sound on this page is made in code by the Web Audio API: no samples, no downloads. Plucked strings, FM piano, mallets, winds, drums made from noise, and a generated reverb.
